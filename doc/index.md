`boot.gl` is the style reset of the Stylescape suite. It gives every project
a predictable starting point by removing or evening out the default styles
browsers apply to HTML elements.

It ships three baselines; use the one that fits:

- **Reset** (`boot.gl.css`): removes all default styling.
- **Normalize** (`normalize.css`): keeps browser defaults and fixes inconsistencies.
- **Reboot** (`reboot.css`): readable, configurable defaults.

Get started with the [Quick Start](quick_start.md).


**boot.gl** is an open-source project by [Scape Press](https://www.scape.press "Scape Press website").
